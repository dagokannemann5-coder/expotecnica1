Proyecto Final Integrador - Programación II + Bases de Datos II + Seguridad Informática + Redes II

## Integrantes
- Kannemann Dago
- Romero Matías

## Descripción
Aplicación web de preguntas y respuestas sobre cultura general argentina.
El jugador responde 10 preguntas, suma puntos y puede ver el ranking.

## Tecnologías
- Backend: Python + Flask (programación orientada a objetos)
- Base de datos: MongoDB (Atlas)
- Frontend: HTML + CSS + JavaScript
